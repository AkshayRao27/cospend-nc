# Release 4.0.1

This release ports cross-project balances and cross-project settlement from Release `v3.0.13-final`, fixes some settlement flow wonkyness, and adds accessibility labels.

It also adds dedicated URLs for cross-project balances and settlement so those views can be bookmarked, reloaded, and restored with browser back/forward.

## Major features

Refer to [Release v3.0.13-final](https://github.com/AkshayRao27/cospend-nc/releases/tag/v3.0.13-final) for feature details.

## Fixes

- Cross-project settlement validation and error handling hardening
- Exclude archived projects and deactivated members from cumulative balance aggregation
- Add deep-link URLs for cross-project balances and cross-project settlement
- Remove duplicate "Close trashbin" action in bill list actions menu
- Add missing aria labels to icon-only/action menu triggers


## Compatibility and migration

- Breaking changes: none (at least intentional)

Extract the archive to your Nextcloud apps directory and enable the app.
